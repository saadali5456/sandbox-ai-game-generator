# Sandbox — AI Game Generator

Sandbox is a work-in-progress full-stack application exploring how generative AI can turn natural-language prompts into playable game experiences.

## Features

- **AI-powered game generation:** Uses the Gemini API to generate game experiences from text prompts.
- **User authentication:** Registration and login functionality.
- **Project management:** Backend APIs for managing user projects.
- **Persistent storage:** PostgreSQL database with Drizzle ORM.
- **Interactive gameplay:** Testing of player movement, coin collection, scoring, enemy collision, and restart functionality.

## Tech Stack

**Frontend:** Next.js, React, TypeScript

**Backend:** Node.js, Express.js, TypeScript

**Database:** PostgreSQL, Drizzle ORM

**AI Integration:** Google Gemini API

## Project Status

Currently under active development and running locally. Public deployment and further improvements are planned.
